# تطبيق زبائن مزاد الصيانة — النموذج التفاعلي

نموذج محلي غير إنتاجي، عربي بالكامل ويدعم RTL والوضعين الفاتح والداكن. لا يتصل بـ Supabase أو أي خادم، ولا يرسل رسائل أو إشعارات أو مواقع أو صوراً حقيقية.

## التشغيل

```bash
pnpm install
pnpm customer
```

افتح رمز Expo في Expo Go بعد ظهور خادم التطوير. رمز التحقق المحاكى في التسجيل وتغيير الهاتف هو **123456**.

## مسار اختبار مقترح

1. وافق على الشروط والخصوصية واقرأ صفحتيهما.
2. أدخل رقماً عراقياً تجريبياً ثم الرمز `123456` وأكمل الاسم والمنطقة.
3. بدّل الوضع الفاتح/الداكن من الإعدادات.
4. أضف مركبة أو عدّل مركبة موجودة.
5. افتح كل بطاقة خدمة، أكمل نموذجاً، راجعه وأرسله.
6. افتح طلب `REQ-1048`، قارن العروض، افتح ملف مقدم الخدمة والمحادثة، ثم اقبل عرضاً واحداً.
7. ألغِ طلباً مع سبب، وقيّم الطلب المكتمل `REQ-1011`.
8. جرّب الإشعارات، الشكوى، تغيير الهاتف، وطلب حذف الحساب وإلغاءه.

كل الأسماء والأرقام والعناوين والأسعار والجهات بيانات خيالية للاختبار فقط.
