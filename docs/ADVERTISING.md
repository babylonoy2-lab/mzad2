# Simulated advertising

Only administration creates/manages banners; providers cannot buy or create them. Banner contracts include ID, Arabic title/description, optional image/button, none/internal/external destination, ISO schedule, order/state, customer/provider/both target, optional user type, and simulated impressions/clicks.

One banner is visible at once; multiple eligible banners rotate every configured few seconds. Pure selection filters application/state/schedule and orders by display order then ID. Future apps should cache optimized WebP variants and remain usable if none load. No asset storage, tracking, upload, external analytics, or real statistics exist in version one.
